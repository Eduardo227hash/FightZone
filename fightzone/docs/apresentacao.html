Projeto de loja virtual

Equipamento para quem vive o boxe.

Uma plataforma para comprar artigos esportivos e administrar uma loja de forma simples.

Experiência do cliente

  • Catálogo, carrinho e finalização de pedidos
  • Conta de cliente e acompanhamento em “Meus pedidos”
  • Cancelamento de pedidos ainda não pagos

Gestão da loja

  • Acesso administrativo com controle por perfil
  • Cadastro de produtos com fotos e gestão de estoque
  • Consulta de pedidos, movimentações e relatórios
Tecnologias
PHP · MySQL · HTML · CSS · XAMPP
Demonstração acadêmica: frete estimado; pagamentos e documento fiscal não são processados por serviços reais.
